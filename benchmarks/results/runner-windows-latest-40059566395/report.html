Method and interpretation

Minimum-norm rows use pivoted QR plus scaled implicit RZ in Kernix; NumPy native lstsq; nalgebra native SVD/solve. Algorithm costs and rank policies differ. Normal residuals and null-space orthogonality are independently checked. See DETAILS.md for thresholds.

Ordinary allocating operations include output allocation and destruction. Explicit reused-output rows exclude pool/output preparation and may have a different recorded affinity. First API call is not a cold-cache measurement.

Native execution may retain thread-local packing scratch. NumPy allocation counts are unavailable. A numeric minimum alone is not a universal performance claim.
